# Paper11 Submission Package

This folder tracks manuscript-submission preparation for Paper11. It is separate
from the executable reproducibility workflow because the repository is a
reviewer-code package and the manuscript is evidence-gated.

## Files

- `01_ijaeog_submission_readiness.md`: target-journal readiness audit for
  International Journal of Applied Earth Observation and Geoinformation
  (IJAEOG).
- `02_draft_titles_highlights_declarations.md`: Phase 42-synchronized guarded
  title, highlight, keyword, cover-letter, declaration, and claim-boundary text
  for a bounded negative/evidence-gated submission route.
- `03_conclusion_manuscript_draft.md`: earlier evidence-calibrated conclusion
  manuscript draft that rejects the current positive Paper11 hypothesis under
  the tested protocol.
- `04_formal_conclusion_manuscript.md`: current Phase 42-synchronized formal
  conclusion manuscript source file for a bounded negative/evidence-gated
  submission route.
- `final/`: generated delivery files, including the DOCX export of the formal
  conclusion manuscript.

## Current Status

As of 2026-07-06, the code/reproducibility repository is ready to cite as a
reviewer-facing artifact, but the Paper11 research manuscript is not ready for
positive performance, suitability-reward, B2/B3, or transfer claims. Phase 40
reports `independent_label_inputs_missing` over `64,984` feature rows and `0`
registry rows. Phase 41 reports `phase41_independent_label_inputs_missing`, and
Phase 42 finds no local Phase 40-passing external suitability label.

Do not submit a main research article claiming model superiority. The current
formal manuscript source file is `04_formal_conclusion_manuscript.md`, and the
current generated DOCX file is
`final/Paper11_formal_conclusion_manuscript.docx`. The source file frames
Paper11 as a bounded negative-results/evidence-gated paper with explicit
representation-control, suitability-gate, prior-gate, and local label-source
audit evidence. If the target is a positive IJAEOG-style research article, the
remaining blocker is an external independent non-leakage label registry plus
new B2/B3 experiments.
