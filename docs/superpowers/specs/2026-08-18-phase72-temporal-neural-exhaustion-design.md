# Phase 72 Temporal Neural Exhaustion Screen Design

## Scientific Question

Does a compact temporal neural encoder recover robust one-year conversion
information from GeoFM history after a strong explicit-history model has
already explained predictable risk? This is a bounded Phase 72 exhaustion
experiment. It is not Phase 72C and it is not a manuscript-writing stage.

## Frozen Scope

The only endpoint is `conversion_1y`, the primary endpoint in the Phase 72
master design and the only endpoint with surviving pooled residual evidence.
The screen reuses the receipt-bound Phase 72B row identities, 2017-2021
training origins, 2022 validation origin, locked 2023 confirmation origin,
both zero-shot transfer directions, and all ten buffered spatial folds.

No two-year neural model is trained in this screen. Decision-aware ranking,
domain regularization, ensembles, uncertainty bounds, reward changes, and
planning are excluded. If the one-year model fails the frozen transfer or
spatial-stability gate, the temporal-neural criterion is closed as mixed or
negative under the available evidence and is not escalated to those omitted
components.

## Residual Architecture

For every validation axis, the explicit baseline configuration is read from
the matching frozen Phase 72B bundle and refitted on that axis's training
rows. Explicit training logits for the neural loss are generated by five-fold
`spatial_block_id` group cross-fitting. The final explicit model is refitted
on all training rows for validation and confirmation prediction.

The residual branch consumes the annual `64`-channel GeoFM history through
origin year `t`:

```text
training-only channel standardization
-> bias-free 64 x 16 projection with tanh activation
-> content gate plus learned relative-position weight
-> masked gated temporal mean
-> bias-free scalar residual head
-> explicit logit + neural residual logit
```

There is no residual intercept. With a zero residual branch, the model exactly
preserves the explicit probability. Padded time steps are masked before
pooling, and every history mask must be a non-empty valid prefix.

Training uses one fixed seed and one frozen AdamW configuration. Validation
labels may select the early-stopping epoch and probability calibrator only;
they do not select architecture width, loss terms, or a family grid.

## Strict Controls

The pooled axis includes five seeds for each original Phase 72B control:

- temporal-order shuffle, preserving the current embedding and shuffling only
  earlier valid years;
- partition-local spatial shuffle within region and origin year;
- a deterministic same-shape `64 x 64` random orthogonal channel projection.

Each control receives the same neural architecture, optimizer, epoch budget,
explicit offsets, and train-only standardization as the primary history. No
control may exchange rows across train, validation, or confirmation
partitions. The strongest validation seed for each control is frozen before
confirmation.

## Gates and Integrity

The practical, bootstrap, strict-control, bidirectional-transfer, and buffered
spatial gates are exactly the Phase 72B gates. Confirmation targets remain
unopened during preparation, runtime benchmarking, fitting, calibration, and
model freezing. The protocol, implementation, tests, prepared manifest, and
selected-model hashes must be committed and pushed before confirmation.

Generated histories, model bundles, validation metrics, predictions, and
receipts remain ignored under `experiments/**/outputs/`. This screen does not
enter Phase 72C, alter rewards, establish agronomic suitability, run planning,
or modify `paper/submission/final/*`.
