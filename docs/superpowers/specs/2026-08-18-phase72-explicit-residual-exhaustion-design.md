# Phase 72 Explicit Residual Exhaustion Screen Design

## Scientific Question

Does temporal GeoFM history explain future land-cover risk that is not already
explained by the strongest frozen explicit-history baseline? This is a
falsifiable exhaustion experiment, not Phase 72C and not a manuscript-writing
stage.

## Frozen Endpoints and Splits

The experiment evaluates `conversion_1y`, `conversion_2y`, and
`noncontinuous_persistence_2y`. It reuses the receipt-bound Phase 72B and
two-year row identities, temporal splits, bidirectional transfer axes, and ten
buffered spatial folds. Confirmation origins remain 2023 for the one-year
endpoint and 2022 for both two-year endpoints.

## Residual Construction

For every endpoint and axis, the explicit baseline candidate configuration is
read from the matching frozen source bundle and all weights are refitted on
that axis's training rows. Explicit training logits used by the residual head
are generated by five-fold `spatial_block_id` group cross-fitting. The final
explicit model is then refitted on all training rows.

The candidate probability is

```text
sigmoid(explicit_logit + standardized_temporal_GeoFM @ beta)
```

There is no residual intercept. The residual features are standardized on
training rows only. L2 strength, class weighting, and calibration are selected
from the frozen grid using validation rows only. This construction prevents an
in-sample explicit fit or a free intercept from masquerading as independent
GeoFM information.

## Controls and Gate

The pooled comparison includes temporal-order shuffle, spatial shuffle, and a
same-dimension random projection, each under seeds 72-76. Control features are
partition-local. The selected control seed is fixed using pooled validation
only. The original Phase 72B practical, statistical, control, transfer, and
spatial gates are reused without modification. All three endpoints must pass
all gates for the overall residual claim to be supported.

## Integrity Boundary

Preparation and fitting must not read confirmation targets. The protocol,
implementation, tests, prepared manifest, and frozen model hashes must be
committed before confirmation. Generated arrays, fitted bundles, predictions,
and receipts remain ignored under `experiments/**/outputs/`. The experiment
does not enter Phase 72C, train a temporal neural model, run planning, alter
rewards, or modify `paper/submission/final/*`.
